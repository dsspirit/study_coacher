# 学习科学贴士库

> 措辞原则：只收主流共识级结论（认知心理学/神经科学/教育心理学教科书级），不给打包票的数字；每条都落到「怎么做」且尽量挂进本库学习循环。zcode 引用时同样遵守：说原理名，不超纲。

| id | 原理 | 一句话 | 怎么做 | 领域 |
|---|---|---|---|---|
| T001 | 间隔效应 | 拉开时间的多次检索，比一次性死磕记得牢得多 | 今天学的东西，睡一觉后明早默写一次，比今晚再读三遍强 | 记忆 |
| T002 | 测试效应 | 主动「捞」记忆的动作本身就在加固记忆，检索即练习 | 合上书默写，写不出来再翻书——别用重读代替检索 | 记忆 |
| T003 | 遗忘曲线 | 不复习的记忆在头几天掉得最快，之后趋于平缓 | 复习排在「快忘未忘」的临界点上，间隔重复系统就是在干这个 | 记忆 |
| T004 | 合意困难 | 感觉吃力的学法往往更有效，感觉流畅的学法常是错觉 | 觉得卡、觉得费劲时不慌，那正是记忆在被加固的体感 | 记忆 |
| T005 | 流畅性错觉 | 读得顺 ≠ 学会了——熟悉感会冒充掌握感 | 重读第二遍之前先问自己：现在合书能说出多少？ | 记忆 |
| T006 | 划线幻觉 | 光划高亮是效果最弱的学习动作之一，划了≈没加工 | 划线之后必须干点什么：写一句自己的话，或当成默写考点 | 记忆 |
| T007 | 生成效应 | 自己想出来的答案，比看到的答案记得牢得多 | 看讲解前先猜一步，错了再对答案，错着记住的更牢 | 记忆 |
| T008 | 精细审问 | 多问一个「为什么是这样」，记忆就多一个挂钩 | 每记一个结论，追问一句为什么，把理由一起记 | 记忆 |
| T009 | 编码特异性 | 在哪学的、怎么学的场景，会成为提取记忆的线索 | 默写时换地方、换纸张、换提问方式，让记忆不挑场景 | 记忆 |
| T010 | 组块化 | 工作记忆只能装 4±1 个组块，打包后才装得下更多 | 把零散知识点串成口诀、流水线、故事线，按「块」背 | 记忆 |
| T011 | 双重编码 | 文字 + 图像两条通道存的记忆，比单一通道牢 | 画一遍流程图/知识地图，比多读一遍文字更值 | 记忆 |
| T012 | 交错练习 | 混着练多种题型，考试时才认得出「这是哪类题」 | 复习时刻意把 ≥2 个主题的题混在一起做 | 记忆 |
| T013 | 睡眠巩固 | 睡眠（尤其深睡）是把白天经历转成长期记忆的归档过程 | 学完当天睡够，等于点了「保存」；熬夜学 = 学了不存盘 | 睡眠 |
| T014 | 睡眠剥夺代价 | 少睡会同时打掉注意力、工作记忆和情绪调节，全线亏 | 备考期最先保的应该是睡眠时间，不是刷题时间 | 睡眠 |
| T015 | 打盹修复 | 20 分钟左右的小睡能恢复警觉性，且不易醒后迷糊 | 午后犯困，定 20 分钟闹钟眯一会儿，别硬扛 | 睡眠 |
| T016 | 作息锚点 | 大脑喜欢可预测的节奏，固定作息降低启动成本 | 默写、刷题、睡觉都尽量卡固定钟点，让身体替你坚持 | 睡眠 |
| T017 | 睡前复习窗口 | 睡前输入的材料在睡眠归档中占比更靠前 | 要背的东西放在睡前最后一轮过，醒来先默写检验 | 睡眠 |
| T018 | 夜猫子/早鸟 | 每个人的警觉高峰时段不同，深浅认知任务各有最佳档 | 把最难的内容排在自己状态最好的时段，机械活排低谷 | 睡眠 |
| T019 | 单线程大脑 | 人不能真的一心二用，「多任务」= 高频切换 + 每次交税 | 学习时全屏材料 + 手机放另一个房间，一次只开一件事 | 注意力 |
| T020 | 手机在场税 | 手机哪怕只是放在桌上不用，也在分走认知资源 | 学习时段把手机放到视线外——不是静音，是离开房间 | 注意力 |
| T021 | 番茄工作法 | 25 分钟专注 + 5 分钟休息，用短周期骗过走神冲动 | 用工作台的番茄钟；休息时离开屏幕，别刷手机（那不是休息） | 注意力 |
| T022 | 超日节律 | 专注力天然以约 90 分钟为周期起伏，硬撑性价比骤降 | 连续高强度 90 分钟后，安排一顿像样的休息再战 | 注意力 |
| T023 | 走神信号 | 走神不是故障，是大脑的默认模式在接管——它是提醒 | 发现走神：不骂自己，标记一下，起身喝口水重启 | 注意力 |
| T024 | 注意力残留 | 从一个任务切到另一个，注意力会残留一半在前者 | 切任务前花 30 秒给上件事写个「暂停点」，再开新的 | 注意力 |
| T025 | 启动成本 | 开始是最贵的一步，进入状态后惯性会接管 | 骗自己「只做 5 分钟」——启动了往往就停不下来 | 注意力 |
| T026 | 环境锚定 | 固定的学习地点会变成「进入状态」的条件反射 | 给学习一个专属座位/桌面，不在床上学（床只留给睡） | 注意力 |
| T027 | 目标梯度 | 越接近目标，动力越强——进度可见本身就在供能 | 盯着工作台的进度条和打卡天数，让「快到了」推你一把 | 动机 |
| T028 | 执行意图 | 「如果 X 就做 Y」的具体计划，远胜「我要努力」 | 把计划写成「晚饭后坐到书桌先默写」，绑时间和地点 | 动机 |
| T029 | 目标具体化 | 「学一点」式目标无法判断成败，大脑不爱追模糊目标 | 每天的目标写成可勾选的块：如「默写 5 张卡 + 答完 1 包」 | 动机 |
| T030 | 小胜利循环 | 动机的燃料是「我行」的证据，不是意志力 | 先安排一个必能完成的小任务开场，用完成感启动大任务 | 动机 |
| T031 | 好奇心加成 | 好奇状态下记忆编码更强——问题本身就是钩子 | 每个块开头先抛给自己一个问题再学，带着悬念读 | 动机 |
| T032 | 自主感 | 自己选的路更愿意走，被逼的事消耗加倍 | 在计划里给自己留选择权：今天先学哪块，自己挑 | 动机 |
| T033 | 进度可视 | 看得见的进度（打勾/天数/经验值）把努力变成游戏 | 每完成一项就打勾，别攒到最后一起勾——即时反馈才有效 | 动机 |
| T034 | 心流条件 | 挑战略高于能力时最容易进入心流，太难太易都出局 | 卡住超 10 分钟就求助或降级任务，顺到无聊就加难度 | 动机 |
| T035 | 元认知 | 「知道自己知道不知道」的能力，决定学习效率的上限 | 每次自测后估分再对答案，校准自己的判断——误差就是弱点地图 | 元认知 |
| T036 | 自我解释 | 用自己的话讲一遍，讲不通的地方就是没懂的地方 | 每读完一节，合书用大白话复述给想象中的 12 岁小孩 | 元认知 |
| T037 | 费曼技巧 | 教别人是最强的学习——教不会的地方就是你不会的地方 | 周六费曼日认真讲，被拷问倒的点就是下周的靶子 | 元认知 |
| T038 | 判断学习 | 「学过」和「学会」之间隔着一次没对答案的自测 | 凭感觉「行了」之前，先来一次白纸默写验收 | 元认知 |
| T039 | 错误价值 | 犯错后纠正的记忆，比一次做对更深——错误是信息 | 错题不是污点是情报：每道错题都定位「哪一步思路错了」 | 元认知 |
| T040 | 反馈时机 | 反馈越及时，修正成本越低——隔天的错已在心里长根 | 答完当天就回 zcode 批改，别让错答案过夜 | 元认知 |
| T041 | 提前测试 | 学前先考一次（考砸也算）能让随后学习更聚焦 | 学新块之前先看自测题，带着「我要找答案」去读 | 元认知 |
| T042 | 学习迁移 | 换个场景还能用出来，才算真学会——默写就是最小迁移 | 复述时刻意换提问角度：如果考官换个问法，我还能答吗？ | 元认知 |
| T043 | 耶克斯-多德森 | 适度紧张表现最好，过度焦虑反而压垮工作记忆 | 考前紧张正常：重读一遍错题本降低未知感，焦虑自然回落 | 情绪 |
| T044 | 焦虑重评 | 把心跳加速解读成「兴奋在供能」而不是「我要完了」 | 默写前心跳快？对自己说：这是身体在调资源，不是警报 | 情绪 |
| T045 | 命名情绪 | 给情绪贴标签能降低杏仁核的警报音量 | 烦躁时写一句「我现在因为 X 感到 Y」，写完往往就能继续 | 情绪 |
| T046 | 自我关怀 | 自责消耗认知资源，善待自己反而更快回到轨道 | 搞砸了一天不骂自己：记一句原因，明早照常开考——节奏比完美重要 | 情绪 |
| T047 | 认知负荷 | 工作记忆是瓶颈，一次塞太多会直接溢出 | 新块一天 ≤2 个，贪多的下场是一个都没存住 | 认知负荷 |
| T048 | 样例效应 | 新手从 worked example 学得快，空手摸索是高手特权 | 学新东西先看完整解题样例，模仿顺了再脱离样例自己来 | 认知负荷 |
| T049 | 有氧运动 | 有氧运动后几小时内记忆编码和情绪状态更好 | 学习日安排 20-30 分钟快走/慢跑，排在难点学习前更赚 | 运动 |
| T050 | 运动即休息 | 换身体劳动是给大脑的真正休息，刷手机不算 | 番茄钟休息段做拉伸/散步/收拾桌面，回来更清醒 | 运动 |
